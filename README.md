# NOVIQUE - Galactic E-Commerce Platform

## 📦 How to Create Your ZIP File

### On Windows:
1. Select all files in the `novique-website` folder
2. Right-click → **Send to** → **Compressed (zipped) folder**
3. Your ZIP file is ready!

### On Mac:
1. Select all files in the `novique-website` folder
2. Right-click → **Compress** 
3. Your ZIP file is ready!

### On Linux:
```bash
zip -r novique-website.zip novique-website/
